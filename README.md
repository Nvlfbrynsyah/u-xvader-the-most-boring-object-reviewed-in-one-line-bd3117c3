One-line review of the dullest, most everyday object I could name. It is a tiny
program whose only real work is a single sentence: a setup that sounds like a
compliment about a workhorse household item, then a turn that uses the one thing
everybody knows about actually handling the object against the name we insist on
giving it. The joke stays inside a factual, physical detail you can picture in your
own kitchen, so the recognition arrives before the punchline does. `main.ts` writes
the line (plus a trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaults to
`/output`, and refuses to write anything that is empty, spills onto more than one line, or
falls outside 1-200 Unicode code points.

## Run it

```sh
node main.ts
node main.ts --help
```
